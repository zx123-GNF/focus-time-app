# 专注时光 · 时间管理 APP

本地运行的时间管理应用，数据统一存储在本机 SQLite 文件（`time.db`），无需联网服务、无需安装任何依赖（使用 Node.js 自带模块）。

## 启动方式

双击 `start.bat` —— 会打开一个独立的桌面应用窗口（Electron），不是网页：
有自己的应用图标和标题栏、无浏览器地址栏、重复双击只聚焦已有窗口、关窗即退出（数据自动落盘）。

其他启动方式：
- 命令行：`npx electron .`（桌面应用）或 `node server.js`（纯浏览器访问 http://localhost:3000）
- 手机访问：让手机和电脑连同一个 WiFi，浏览器打开 `http://<电脑IP>:3000`（首次运行如弹出防火墙提示请点"允许"）

## 五大板块

每个板块有专属的矢量高清背景（首页-暖阳晨曦 / 专注-极简计时环 / 日程-紫境日历 / 统计-青绿数据 / 我的-粉橘晚霞），卡片为半透明毛玻璃效果；背景文件在 `public/bg/` 下，替换同名 SVG 即可换肤。

1. **专注**：白色简洁界面，圆形计时器 + 开始/暂停/结束按钮；「专注事情」可选 数学 / 英语 / vibe coding，也可「＋自定义」添加自己的项目；结束自动保存专注记录，显示今日各任务专注汇总。
2. **首页**：天气（默认北京，点卡片可换城市）、喝水提醒（间隔可调、可记录杯数）、睡觉提醒（到点弹窗）、每日一言、联系人（通过手机号添加，若对方也是本应用用户会自动标注）。
3. **计划日程**：三档划分——紧急（红）/ 中等（黄）/ 悠闲（绿）；点右下角 ＋ 添加任务，可设置自定义任务名、开始时间、最迟时间、时间紧张程度和备注；可勾选完成、超期自动标红。
4. **使用统计**：进入后申请「应用使用时间访问权限」；授权后展示今日各 APP 使用时长占比、近 7 天总览，并真实统计你在本应用内各页面的停留时长。
   > 说明：浏览器无法读取手机系统里微信、抖音等 APP 的真实时长（安卓原生版需用 UsageStatsManager），因此系统 APP 部分为演示数据，本应用内页面为真实统计。
5. **我的**：头像（emoji 或图片链接）、昵称、手机号（需密码验证）均可修改；底部显示版本号 v1.0.0、应用信息；支持退出登录。

## 文件结构

```
time-manager-app/
├── electron-main.js # Electron 桌面窗口（自动拉起后端）
├── server.js        # 后端服务 + SQLite（零依赖）
├── make-icon.js     # 应用图标生成脚本
├── start.bat        # 一键启动桌面应用
├── time.db          # SQLite 数据文件（首次启动自动生成）
└── public/
    ├── index.html   # 页面结构
    ├── style.css    # 样式
    ├── app.js       # 前端逻辑
    └── icon.png     # 应用图标
```
